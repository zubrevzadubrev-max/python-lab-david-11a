# PY / LAB

Автор: **Русинов Давид, 11А класс**.

Адаптивный сайт на русском: шесть уроков, редактор настоящего Python через Pyodide, тест из 10 вопросов, разбор ответов и именной сертификат SVG. SVG можно открыть в браузере и распечатать в PDF. Сертификат учебный, не является документом об образовании.

## Запуск на компьютере

Откройте терминал в этой папке и выполните:

```powershell
python -m http.server 8080
```

Откройте http://localhost:8080. Также можно дважды нажать `start.bat`. Для редактора нужен HTTP-сервер: запуск через file:// не подходит для Web Worker.

Для первоначальной загрузки Python, фотографий Unsplash и шрифта Google Fonts нужен интернет. Интерфейс использует системный шрифт, если Google Fonts недоступен. Прогресс, имя и лучший результат сохраняются локально в браузере. Проверка результата учебная, без серверной верификации. Python исполняется в отдельном worker с ограничением 10 секунд; input() в этом редакторе не поддерживается. Не вводите секретные данные в исполняемый код.

## Публикация через GitHub Pages

Загрузите содержимое этой папки в публичный репозиторий. В Settings → Pages выберите Deploy from a branch, ветку main и папку / (root). Сборка не требуется. Все пути относительные, сайт совместим с подпапкой GitHub Pages.

Фотографии: Unsplash (внешние изображения). Исполнение Python: Pyodide через jsDelivr. HTML/CSS/JS сайта не требуют npm или сборки.
